Squash Gateway

tech cast — hackathon build

An enterprise platform that cuts AI API costs by compressing prompts before they ever reach the model. A Chrome extension intercepts prompts inside ChatGPT, Claude, and Gemini and compresses them in real time; a FastAPI backend handles routing, redaction, and token accounting.

  • Compression engine built on Microsoft's LLMLingua-2 (XLM-RoBERTa-Large), with a frequency-based fallback
  • Four-layer safety system — length guard, dynamic ratio scaling, neural compression, and a context handbrake that reverts compression if negation words get dropped
  • PII redaction with round-trip restoration, tiktoken-based token counting, and multi-provider routing (OpenAI, Anthropic, Google, custom endpoints)
  • Manifest V3 extension using MutationObserver-based composer detection and a keyboard shortcut for one-tap compression
  • Dark-themed React/Vite/Tailwind dashboard with live backend data and usage charts
